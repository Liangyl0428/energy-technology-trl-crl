# NMF500主题下的TRL/CRL重算

本轮把新NMF500主题目录接入既有的独立证据门槛引擎，并提供热点联合表。
主题ID使用 `N0001` 至 `N0500`，对象保留原case_id和scope_id。
对象名称、配置、功能、已接受来源题名和引文用同一完整BGE-M3编码；
391个已有候选方向用名称与功能编码。编码文本不含TRL/CRL阶段。

候选关联按论文主题中心余弦取Top3，保留余弦、top1–top2间隔和待审阅
状态。所有新关联仍需语义确认，不能把相似度阈值解释为领域映射准确率。
主题目录、技术方向和有界评价对象是不同层次；一个案例的成熟度不能
传给整个主题。500个主题的TRL/CRL统一值始终留空。

122个对象从原始判据、观测和必要引文重新计算。没有读取旧结果中的等级
作为输入；检查新目录关联是否意外改变对象等级。此次不增加外部证据，
也不把旧391个方向声称为由新主题重新发现的391种技术。

结果中的 `theme_evidence_profiles.json` 展示各主题的候选关联案例分布，
`case_hotspot_links.csv` 连接热点数值指标与同对象的TRL/CRL阶段。
`500主题热点与TRL_CRL.xlsx`集中展示目录、对象、Top3关联、来源和缺项。
没有案例的主题保持未覆盖，不自动填1级或估计一个等级。

运行顺序（原始工作区根目录）：

```sh
# Python 3.10：复用工作区已有BGE-M3 ONNX GPU运行时。
python3 energy-technology-trl-crl/pipelines/nmf500/encode_context.py
# 先完成energy-topic-hotspots/pipelines/nmf500/build.py及review.py。
.venv-hotspots/bin/python energy-technology-trl-crl/pipelines/nmf500/build.py
cd energy-technology-trl-crl
../.venv-hotspots/bin/python -m trl_crl validate --data work/nmf500/inputs --output results/nmf500
```

`work/nmf500/inputs`是重新关联后的隔离输入，`results/nmf500`保存结果；
原有证据和默认750主题结果路径仍可独立复现。数据依赖及哈希见
`PROVENANCE.json`、`INPUT_CHECKSUMS.json`。

证据截止2026-09-25，热点趋势截止2026-06-30，二者分别列示。统计范围是
本轮冻结分类样本，不能替代原约512万条记录的全量分析。

本轮实际复算122个对象：109个有TRL证据阶段、24个有CRL阶段、14个同对象
双轴齐全、3个双轴未知。500个主题中94个有Top1候选案例关联，406个无
此类案例覆盖；所有主题关联仍待核读。主题变更未改变任何对象的证据
等级。本轮原证据引擎的11项测试、结果的10项复算校验均通过。
