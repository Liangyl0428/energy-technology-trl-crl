# 全量主题关联后的 TRL/CRL 消融与灵敏度

入口为 pipelines/full_nmf/experiments.py，参数 --classification 指定全量分类目录，--input 指定全量成熟度关联目录，--output 指定实验输出。

等待全量主题中心、全部专利政策匹配和基础下游结果完成，再使用新的F主题映射运行既有评估引擎的全部证据实验，不复用旧CSV结果。基于现有全部有界技术对象及公开证据，不意味着512万条记录都获得了成熟度判据证据。

覆盖来源、引文和观测留一，来源类型消融，各轴及各判据支持撤回，证据可用日期敏感性，以及新主题关联Top1/Top3、余弦和Top1–Top2差距网格。移除必要支持只撤回证据判断，不删除标准中的必要判据；校验不会无故升档，并检查TRL/CRL两轴独立性。

新增逐对象证据脆弱性与全量主题／热点关联。主题级TRL/CRL仍留空；结果变化表示文档支持减少，不表示技术实际退步。已有证据可用日期有限，早期截断产生未知不能当作历史成熟度轨迹。

实验汇总绑定分类摘要、完整输入证据和新映射的SHA-256；结果目录有文件清单和完成标记。完整实验、相关测试和三个仓库校验全部通过后，独立后续任务更新本地结果，并提交、非强制推送既有origin/main。若发生远端或本地并发修改则停止发布，不覆盖用户工作。

本次发布还必须通过[主题效果对比](TOPIC_EVALUATION.md)的输入／输出校验；共同口径对比副本位于 assets/full_nmf500/topic_evaluation。主题几何质量、关键词一致性不等于技术成熟度判断的正确性。
